==============================================================================
TAB 1 — API & Story Info
==============================================================================
Purpose: Config + high-level story spine.

Controls / attributes:
  apiKey, model, maxTokens, genre, authorStyle, styleGuide, title,
  storyArc, generalPlot, setting, numChapters, chapterLength,
  Import Session / Export Session, authors / author (fetched list + selection)

AI actions: Suggest Story Arc / Plot / Setting, AI Suggest Story Info,
Fetch authors / style guide.

novelData: apiKey, model, maxTokens, genre, title, storyArc, generalPlot,
setting, numChapters, chapterLength, authorStyle, styleGuide, authors, author

==============================================================================
TAB 2 — Characters
==============================================================================
Purpose: Cast list sized by numCharacters.

Controls:
  numCharacters
  Per character: name (.charName), backstory (.charBackstory), arc (.charArc)

AI actions: Scrape Book Info for Characters, Suggest Characters,
Add Another Character, Refine Characters with Subplots

Rules: blank slots only on Suggest; fully-defined characters locked as context;
extra LLM characters beyond numCharacters dropped; name-only rows get
backstory+arc from book context.

BACKSTORY RULE (LOCKED): backstory must support the character and their
chapter roles — motives, wounds, relationships, why they act in beats.

novelData: characters[] = { name, backstory, arc, ... }

==============================================================================
TAB 3 — Subplots
==============================================================================
Purpose: Secondary threads (often minor conflicts / side arcs).

Controls: minSubplots, one textarea per subplot
AI: AI Suggest Subplots, Add Another Subplot
Generated subplot target length: ~300–400 words (when AI fills)
novelData: subplots[]

==============================================================================
TAB 4 — Outlines
==============================================================================
Controls: novelOutline, plotOutline, storyArcOutline, chapterBlueprints,
outlineImprovements; per-chapter chapterOutlines[i], chapterArcs[i]
AI: AI Suggest Novel Outline, Incorporate Suggestions,
Generate Chapter Outline & Arc, Update
novelData: novelOutline, plotOutline, storyArcOutline, chapterBlueprints,
chapterOutlines, chapterArcs, outlineImprovements, chapterImprovements

==============================================================================
TAB 5 — Generate Chapters
==============================================================================
Controls: per-chapter Generate; continuityStrictMode; autoContinuityAudit;
continuityStatusPanel; packets / tracker / findings
Uses: chapter outline/arc, characters, subplots, authorStyle, styleGuide,
chapterLength, continuity
novelData: chapters, continuityStrictMode, autoContinuityAudit,
chapterContinuityPackets, continuityTracker, continuityFindings

==============================================================================
TAB 6 — Edit Chapters
==============================================================================
Controls: edited chapter text, Improvements to Implement,
Update Chapter, Check Spelling & Grammar
novelData: editedChapters, chapterImprovements

HOW CONFLICTS / ARCS MAP TODAY (until you pick counts)
==============================================================================
Major conflict(s)      -> storyArc + generalPlot (+ storyArcOutline / plotOutline)
Minor conflict(s)      -> subplots[] + secondary beats in character arcs
Related character arcs -> characters[].arc + chapterArcs[] + continuity arc progress
Backstory support      -> characters[].backstory (LOCKED to support chars + chapters)
